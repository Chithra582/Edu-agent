# MCP Server & Client Mastery

## Overview
Teaches the architectural principles of the Model Context Protocol (MCP), enabling students to build standardized tool servers, expose system resources, and connect agents to external data.

## Key Capabilities
- MCP TypeScript and Python SDK server creation.
- JSON-RPC protocol inspection and debugging.
- Integration with Claude Desktop, Cursor, and custom agent harnesses.
